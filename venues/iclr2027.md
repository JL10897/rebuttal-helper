# ICLR 2027: rebuttal and discussion rules

Looked up on 2026-11-13 from the official ICLR 2027 pages. Each item gives its source. "Not found" means the official pages did not say; do not fill it in from another year. Confirm this file with the author before using it.

Platform: OpenReview (see `venues/openreview.md`).

| Item | Rule | Source |
|---|---|---|
| Discussion period | Author-reviewer discussion Nov 5 to Nov 18, 2026; reviews released Nov 5. | [Dates](https://iclr.cc/Conferences/2027/Dates), [Author Guide](https://iclr.cc/Conferences/2027/AuthorGuidelines) |
| Time zone of the deadline | Not found. The dates page does not state a time zone for these dates. | [Dates](https://iclr.cc/Conferences/2027/Dates) |
| After the discussion | Reviewer-AC discussion and meta-reviewing Nov 19 to Dec 16 (dates page); reviewer guide puts reviewer-AC discussion at Nov 19 to Nov 25, then optional borderline discussion Nov 26 to Dec 2. Decisions Dec 16. | [Dates](https://iclr.cc/Conferences/2027/Dates), [Reviewer Guide](https://iclr.cc/Conferences/2027/ReviewerGuidelines) |
| Length of one comment | The author guide says "There is a word limit for each comment" and gives no number. The number to use is what the OpenReview comment form enforces: 5,000 characters, as observed by the author in the form during this cycle. Re-check in the form. | [Author Guide](https://iclr.cc/Conferences/2027/AuthorGuidelines); OpenReview comment form |
| Number of comments | No limit; split a long reply across several comments. | [Author Guide](https://iclr.cc/Conferences/2027/AuthorGuidelines) |
| Revised PDF | Allowed until the end of the discussion period (Nov 18). Reviewers and ACs need not read every revision; a pdfdiff against the submission is applied. ACs and reviewers may ignore changes that make the paper significantly different. | [Author Guide](https://iclr.cc/Conferences/2027/AuthorGuidelines) |
| Page limit of the revision | 10 pages (the camera-ready limit), raised to allow new results and discussion. References and appendices do not count. | [Author Guide](https://iclr.cc/Conferences/2027/AuthorGuidelines) |
| Marking changes | Not required in a specific form (no color rule found). The author guide asks authors to communicate clearly what changed. | [Author Guide](https://iclr.cc/Conferences/2027/AuthorGuidelines) |
| Anonymity | Double-blind: authors and reviewers stay anonymous to each other. | [Author Guide](https://iclr.cc/Conferences/2027/AuthorGuidelines) |
| External links | Allowed if completely anonymous; make sure the host does not track visitors. Code can be shared as an anonymous repository link in a comment visible to reviewers and ACs only. | [Author Guide](https://iclr.cc/Conferences/2027/AuthorGuidelines) |
| Image hosting | Not found. | |
| New experiments | Allowed. Reviewer guide: requested experiments should be limited in scope and validate existing results; new experiments should not significantly change the content of the submission. | [Reviewer Guide](https://iclr.cc/Conferences/2027/ReviewerGuidelines) |
| LLM use in responses | Not found for responses specifically. The AI policy makes authors responsible for all content and treats LLM-produced falsehoods as a Code of Ethics issue. | [AI Policy for Authors](https://iclr.cc/Conferences/2027/AIPolicyForAuthors) |
| Comment readers | Comments can be restricted to reviewers, ACs or PCs. | [Author Guide](https://iclr.cc/Conferences/2027/AuthorGuidelines) |

For `points.json`: `"char_limit": 5000`.
