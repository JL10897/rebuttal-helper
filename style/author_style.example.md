# Author style archive

Copy this file to `style/private/author_style.md` (that folder is ignored by git, so your rules and references stay private) and keep it there. The style box on the compare page is filled from it, and every model that drafts a reply receives the style box as its system prompt.

End each rule with its date and source in brackets: which paper, which feedback. A rule here holds for any paper. A special case tied to one reply, one reviewer or one sentence belongs in that point's brief, not here.
